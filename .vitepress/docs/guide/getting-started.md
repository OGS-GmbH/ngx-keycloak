# Getting started

## What's inside?

A package that provides a seamless interface for integrating Keycloak authentication into Angular applications. It simplifies communication between Angular and Keycloak, handling token management, session control, and user authentication. 


## Installation


### Prerequisites

- Node.js version 18 or higher
- A package manager: e.g. npm, pnpm, ...
- A Node.js-based project


Install `@ogs-gmbh/keycloak` using your preferred package manager:

::: code-group

```bash [npm]
$ npm install @ogs-gmbh/keycloak
```

```bash [pnpm]
$ pnpm install @ogs-gmbh/keycloak
```

```bash [yarn]
$ yarn add @ogs-gmbh/keycloak
```

```bash [bun]
$ bun add @ogs-gmbh/keycloak
```

:::
